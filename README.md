# Desať prstov

Free trainer for typing with all ten fingers on the Slovak (QWERTZ) keyboard.
Made for classmates at the business academy as an alternative to the paid ATF app.

## Run it

Open `index.html` in a browser (Chrome, Edge or Firefox). Nothing to install.

## Features

- **Lekcie (lessons):** lessons 1–66 in the same order and numbering as the class textbook (keys, Shift, Caps Lock, diacritics, punctuation, numbers). The exercises are generated by the app, not copied from the book.
- **Slová (words):** only real Slovak words per lesson, built from the letters learned so far (word list in `js/words.js`, ~1100 words). Choose 1, 3, 5, 10 or a custom number of lines (1 line ≈ 60 characters).
- **Opakovanie (review):** drills the words you got wrong and your weakest keys, and lets you paste and save word lists from class. **Načítať z fotky** reads the text from a photo of a page (Tesseract.js with Slovak, runs in the browser; the first use needs internet to download the language data).
- **Mistake mode:** a button switches between *zastaviť* (stop until you press the right key) and *pokračovať* (keep going, Backspace fixes).
- **On-screen keyboard:** finger colours, the next key glows, dead-key hints for ó, ď, ĺ, ŕ.
- **Štatistiky (stats):** keystrokes per minute, WPM, accuracy, streak, progress charts, a heatmap of mistakes per key, slowest keys, missed words, history, and backup/restore.
- **Hry (games):** Word Rain, a 60-second Sprint and Letter Hunt. *Skopírovať výzvu* copies a challenge link, so a classmate plays the same words and tries to beat your score.

## Design

Swiss Modernism 2.0: strict grid, Archivo + JetBrains Mono, black/white with one accent (`--accent` in `css/style.css`), thin rules instead of shadows, no gradients or emoji. Light and dark themes (button in the header, or follows the system setting). All colours are CSS variables at the top of `css/style.css`.

All data stays in the browser (localStorage). Use *Uložiť zálohu* on the stats page to move it to another computer.

## Lessons and words

Lessons are in `LESSONS` in `js/data.js` (`n` = textbook lesson number, `keys` = new keys, `type` = special lesson kind). Exercises are generated from the keys learned so far, using the word list in `js/words.js` — add more words there anytime.

Text from your own textbook pages can be loaded with **Opakovanie → Načítať z fotky**.

## Files

| File | What it does |
|---|---|
| `js/data.js` | keyboard layout, lessons, Slovak word list |
| `js/typing.js` | typing engine (both mistake modes, dead keys) |
| `js/exercises.js` | builds texts for lessons and review |
| `js/keyboard.js` | on-screen keyboard and finger hints |
| `js/games.js` | minigames and challenge links |
| `js/stats.js` | stats page and charts |
| `js/store.js` | saving to the browser |
| `js/app.js` | navigation and screens |
